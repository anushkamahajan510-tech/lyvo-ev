---

## 🛠️ Features
- **Smart Discoverability Search:** Instant client-side keyword and intent search for models, specs, dealers, and corporate info.
- **Showroom Studio Stage:** High-resolution product showcase with zoom controls (1x, 1.35x, 1.65x), view reset, and 360° asset pipeline documentation.
- **Vehicle Colour Customisation:** Live switcher between *Signature Dual-Tone*, *Onyx Black*, and *Pearl White*.
- **Direct Quotation Engine:** Pre-fills requested vehicle and color variant, with input validation for Indian mobile numbers.
- **Responsive Automotive UI:** Optimized across mobile (375px, 430px), tablet (768px), and desktop (1024px, 1440px).

## 💻 Local Development
To run the website locally:
```bash
python3 server.py
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## ☁️ Deployment on Vercel
This repository is pre-configured for seamless zero-config deployment to **Vercel**:
- `vercel.json` provides clean URLs (`cleanUrls: true`), static asset caching headers, and direct routes for product detail pages.
- Framework Preset: **Other**
- Root Directory: `./`
